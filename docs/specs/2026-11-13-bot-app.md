# 类 lorca 的桌面 Bot 应用

2026-11-13 与用户议定。取代 BLUEPRINT 的 all-in-one 定位（见 ADR 0006）。

## Why

all-in-one（Mail / Task / Knowledge / Note / Spaces）范围过大，迟迟不能成为一个好用的产品；这些能力以后可由插件或 Bot 接入。用户现在要的是一个像 lorca 的桌面 Bot 软件：管理 Bot、同时和多个 Bot 长线对话、配置模型。

## Goal

用户打开 MyAid，左侧是扁平的 Bot 列表，中间是可平铺多个对话面板（Pane）的分屏区，每个 Bot 只有**一条长对话**，历史可沿右侧的历史轨翻阅；Bot 详情从 Pane 顶部打开为弹窗；设置页可配模型供应商、语言 / 外观、查看后台连接与版本。整套界面中英双语。手机端与多端（经 Relay 连回桌面本机）仍是目标，本轮不实现。

## Out of scope

- Mail、Task、Knowledge、Note、Spaces 的任何界面与文档定位（移除）
- 手机端界面、Relay 配对（目标保留，本轮不做；手机目标形态：单栏，Bot 列表 → 长对话，Bot 详情为全屏页）
- 群聊（未来作为左侧列表的另一种条目，本轮不做）
- Pane 的标签页（Tab）
- 段（Session）的单独归档或删除
- 新增自定义模型供应商
- 在旧段里继续发送

## Acceptance criteria

### 左侧列表

- [ ] **用户**看左侧，**看到**：搜索框、Pin 区（置顶的 Bot）、其余 Bot 按最近活动排序、「＋ 新建 Bot」、底部 Host 状态点与 ⚙；**没有** Mail / Task / Knowledge / Spaces / Dialogues / Settings 分区，Bot 下**不展开**会话。_(automated)_
  - Example：有 Ada、Bob 两个 Bot，Bob 刚回复过 → 列表顺序 Bob、Ada；Bob 带未读数 1。
- [ ] **用户**右键 Ada → Pin，**看到** Ada 移到 Pin 区；重启后仍在。_(automated)_
  - Example：Pin Ada → Pin 区只有 Ada；Unpin → 回到按活动排序的位置。
- [ ] **用户**在 Bob 工作时，**看到** Bob 旁的「工作中」绿点；回复完成且窗口不在前台时收到通知。_(manual)_
  - Example：Bob 正在生成 → 绿点；完成 → 绿点消失，系统通知「Bob 回复了」。
- [ ] **用户**归档 Ada，**看到** Ada 从列表消失；在搜索里输入 Ada 能找回并取消归档。_(automated)_

### 分屏区（Pane）

- [ ] **用户**点 Ada，再把 Bob 拖进分屏区右侧，**看到**两个 Pane 并排各自对话；可横向 / 纵向再拆、拖动分隔线调整大小、关闭 Pane；⌘ 快捷键切换焦点。_(automated)_
  - Example：Ada | Bob 左右并排，再在 Bob 下方拆出 Cleo → 三个 Pane 同时可见，三个都能同时流式回复。
- [ ] **用户**重启应用，**看到**分屏布局与各 Pane 的 Bot 原样恢复。_(automated)_
- [ ] **用户**点一个已在某 Pane 打开的 Bot，**看到**焦点切到那个 Pane，不开第二个。_(automated)_
  - Example：Ada 已在左 Pane，焦点在右 Pane，点 Ada → 左 Pane 获得焦点。
- [ ] **用户**在 Pane 顶部（与拆分 / 关闭控制并排）点「Bot 详情」，**看到**弹窗：Profile、Runs with（模型、thinking）、Skills、Plugins、默认工作目录、删除 / 归档，以及当前段的工作目录、模型、用量 / 上下文与 Compact。Pane 内不再有侧抽屉 Inspector。_(automated)_
  - Example：在弹窗改 Ada 的名字为 Ada Lovelace → 保存后列表与 Pane 标题都更新。

### 一个 Bot 一条长对话

- [ ] **用户**打开 Ada，**看到**一条连续的对话：多个段按时间相连，段之间有分隔线（日期 + 工作目录）；向上滚动自动加载更早的段。_(automated)_
  - Example：Ada 有 11/02（~/proj-a）、今天（~/proj-b）两段 → 中间分隔线「今天 · ~/proj-b」。
- [ ] **用户**看对话右侧的历史轨，**看到**每段一个刻度，当前段高亮；悬停显示该段标题与时间，点击跳到该段开头。_(automated)_
- [ ] **用户**只能在最新段发送；滚到旧段时，输入框仍发往最新段，旧段内容可复制、不可在其中续聊。_(automated)_
- [ ] **用户**在命令面板选「新话题」或输入 `/new`，**看到**新的一段开始（新分隔线），之前的内容仍在上方。_(automated)_
  - Example：输入 `/new` → 出现分隔线「今天 · ~/proj-b」，下一条消息进入新段。
- [ ] **用户**在 Pane 标题处把 Ada 的工作目录从 ~/proj-a 改为 ~/proj-b，**看到**自动开始新的一段，分隔线显示 ~/proj-b；旧段仍显示 ~/proj-a。_(automated)_
- [ ] **用户**在上下文接近上限时，**看到**同一段内的 Compact，而不是自动新开一段。_(manual)_
- [ ] **已有数据的用户**升级后打开 Ada，**看到**原来 Ada 名下多个 Dialogue 的所有会话合并成 Ada 的一条长对话，按时间排序，什么都没丢；旧注册表有备份。_(automated)_
  - Example：Ada 原有「Ada · proj-a」2 个会话、「Ada · proj-b」1 个会话 → Ada 长对话里 3 段。

### 设置

- [ ] **用户**点 ⚙ 或按 ⌘,，**看到**整页设置覆盖主区域，左侧分组：模型供应商 / 通用 / 后台 / 关于；Esc 或「返回」回到原分屏布局，Pane 不变。_(automated)_
- [ ] **用户**在「模型供应商」为 DeepSeek 填 API Key 并保存，**看到**状态变为「已配置」；Key 不出现在 `~/.myaid` 的任何文件里（2026-11-14 修订，见「修订」）；清除后状态变回「未配置」。可编辑 base URL 等供应商字段，可选默认模型。_(manual + automated)_
  - Example：填 `sk-…` → 「已配置」；新建会话使用所选默认模型回复。
  - Example：Host 未连接 → 页面说明「需要连接 Host 才能配置供应商」，输入框禁用。
- [ ] **用户**在「通用」把语言从简体中文切到 English，**看到**整个界面（侧栏、Pane、弹窗、设置、菜单、通知、错误提示）都变为英文，无残留中文；默认跟随系统语言。_(automated)_
- [ ] **用户**在「通用」选外观（跟随系统 / 浅色 / 深色），**看到**立即生效，重启后保留。_(automated)_
- [ ] **用户**在「后台」**看到** Host 与 dsh web 的连接状态、dsh 实际版本与支持的版本、最近错误；可启用 / 停止 / 重启后台服务。_(manual)_
  - Example：dsh 版本与支持版本不一致 → 显示两者并说明「版本不匹配，Host 拒绝启动」。
- [ ] **用户**在「关于」**看到** MyAid、Host、dsh 版本；点「复制诊断信息」得到一段包含这些版本与连接状态的文本。_(automated)_

## 修订

- **2026-11-14**（与用户议定）：「Key 不出现在 `~/.myaid` 的任何文件里」改为——**MyAid 自己的文件（注册表、偏好、日志）里没有 Key；Key 只存在 dsh 的凭据库，清除后引用为空。** 原因：`~/.myaid` 同时是 dsh 的数据目录，dsh 官方把凭据存在其中的 `.credentials.yaml`，原字面不可满足。
