# MyAid 产品蓝图（原则版）

描述产品目标与业务规则的**原则层**；装配与协议细节见 [ARCHITECTURE.md](ARCHITECTURE.md)，DSH 集成原则见 [DSH_PRINCIPLES.md](DSH_PRINCIPLES.md)。实现进度见根 [README.md](../README.md)。

本文件改编自 `~/Code/dsh-bot/docs/BLUEPRINT.md` 中与 Harness / Host / 注册表相关的不变式，产品叙事改为 MyAid（个人助理操作系统），**不**照搬「DSH Bot」工作台 UI 规格。

## 产品定位

MyAid 通过对话交付结果，用任务与结果跟踪进度，用记忆与知识认识你，用插件扩展双手。桌面 UI 是控制端；独立 Host + 官方 `dsh` 管理执行。关闭 UI 不停止已接纳工作；遇审批时可能等待用户重连。

## 后台运行与升级

- 首次打开只查询后台状态；用户明确「启动后台」才申请登记 / 启动。
- 系统禁用后台后不自动改用其他常驻方式；保留数据与修复入口，恢复批准后仍须明确启动。
- 升级默认等待无活动执行、待处理输入与待审批；「立即升级」须确认。保留 Session / 队列 / 核对记录；不补发输入、不自动答复审批。

## 对话与对象模型（原则）

决定见 [ADR 0001](adr/0001-bot-has-many-sessions.md)。对象与 DSH 的映射图见 [BOT_SESSION_MAP](BOT_SESSION_MAP.md)。

- Bot 是启动身份，名下可以有多条会话。每条会话是一项对话任务，并等于一条 Harness Session。
- 会话只在用户进入某个就绪 Bot 后明确新建，并立刻认领给这个 Bot。草稿没有会话。打开、初始化、修改能力都不自动新建。跨 Bot 的会话列表不新建。
- 新建是另一项任务。正在执行的会话留在原会话上，并在两个视图里可见。
- 注册表认领会话：一条 Session 只属于一个 Bot。dsh 保存事件日志。未被认领的 Session 不是产品会话。
- Bot 视图与会话视图是同一份认领的两种看法，可以从任一边进入另一边。进入 Bot 时先看到该 Bot 的会话列表，不自动打开某一条对话。
- 模板与工作区在首次初始化后固定；该 Bot 的全部会话共用这一工作区。不同组合新建 Bot。默认模型与能力属于 Bot，会话不另存一套。
- 同一工作区路径同时只有一条会话可以执行。路径不同则可以各自执行。产品不要求路径在 Bot 之间唯一。
- 可先保存未就绪对象，条件满足后再初始化；失败保留草稿与修复入口，结果未知先核对。
- 执行结束不等于这项任务结束。归档作用在会话认领上：阻止新输入，保留历史与未决审批，不能取消，也不删除 dsh Session。正在执行时先停止或等这轮结束，再归档。归档不让 Bot 退役。
- Bot 只有草稿和就绪。只有从未认领过会话的 Bot 可以删除。会话不删除。认领还在但 dsh 已无此 Session 时标成待核对，不自动解除；用户确认缺失后可以解除认领，该 Bot 仍算曾经有过会话。
- 有未决审批时留在该会话及其所属 Bot 上，审批仍可答复。同 Bot 的其他会话、其他 Bot、跨 Bot 会话列表，都要等答复之后才能打开。缺少审批界面不能默认放行。
- Tasks、Outcomes 不是会话，本次不定义。

## 配置所有权

| 真源                | 内容                                         |
| ------------------- | -------------------------------------------- |
| dsh / 上游 settings | 模型供应商、端点、凭据（密钥不入客户端文件） |
| 桌面注册表          | 名称、模板引用、工作区、默认模型、会话认领   |
| 界面偏好            | 主题、窗口等非关键状态                       |

桌面独占写注册表；移动端（未来）只读快照。

## 输入与状态

- 发送前保存稳定请求标识与正文；超时 ≠ 未接纳。
- 区分草稿、发送待确认、已接纳、执行中、执行结束；这些状态按会话各自计算。执行结束 ≠ 这项任务结束。
- 停止当前执行、撤回未领取输入、停止后台为三项独立操作。
- 首版可先交付纯文本；附件与记忆为后续阶段。

## 能力与扩展

- 初始化把模板当时映射的 Agent preset id 绑定到该 Bot。未初始化时跟随模板当前的 preset。单独配置某个 Bot 的能力时改用插件侧派生的 preset id，模板引用保持不变。
- 该 preset 是这个 Bot 每条会话的启动身份。保存后，正在执行的一轮继续用开始时的配置；空闲后用同一 Session id 与新 preset 恢复。
- 需授权的工具调用必须可审批；缺少审批 UI 不能默认放行。
- 产品插件见 `packages/myaid-plugin-*` 与 [DSH_PRINCIPLES.md](DSH_PRINCIPLES.md) §4。

## 多端（目标）

手机不打包后台；经 Relay 转发密文；Bot / 凭据只在桌面管理。配对与可靠性另案设计。

## 验收（原则）

- 仅支持经本机验证的官方 `dsh` 版本；不兼容时阻止发送并保留草稿。
- Host 控制协议与客户端原生适配须联调；`SMAppService` 以签名成品为准。
